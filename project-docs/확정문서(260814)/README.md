## 핵심 변경 4가지

**1. P-08(교육 과정 상세) 폐지.** 교육 과정 목록(P-07)과 별도의 상세 페이지를 두지 않고,
목록 카드를 펼쳐 커리큘럼을 같은 화면에서 보여주는 방식으로 바꿨다. 화면 수 22→21종,
REQ-F-031(수료 빌더 역방향 노출)도 함께 폐지됐다. P-06의 "수료 과정" 링크는 텍스트 표기로만
남는다.

**2. 디자인 시안2 채택 + 퀄리티 상향 요구.** 클라이언트에게 두 시안(정적 카피 중심 / 섹션별
인터랙션 다양화)을 전달했고, **인터랙션 다양화 시안**이 "더 AI스럽지 않다"는 판단으로
채택됐다. POL-11①-1(섹션마다 인터랙션이 달라야 함)이 클라이언트에게 직접 검증된 것이다.
다만 **완성도를 더 높일 것**을 요구했으므로 다음 단계는 새 화면 추가가 아니라 상세 페이지
디자인·마이크로 인터랙션·카피를 다듬는 데 집중한다.

**3. 시안1 카피 채택 검토.** 팀장 판단으로 시안1(정적 카피 중심 시안)의 카피 중 재사용 가치가
있는 문구들을 카피 전략 보고서에 "채택 검토" 표로 반영했다. 확정 카피가 아니라 참고 후보이며,
최종 채택 여부는 각 화면을 작성하는 팀원의 재량이다.

**4. 경쟁사 분석 필수 → 선택 전환.** 컨펌 문서에 실은 경쟁사 4곳(TenAI·세컨팀·TreeSoop·
DevTeam Korea)에 대해 "대부분 잘 안되는 업체라 참고 가치가 낮다"는 피드백을 받았다. 앞으로
경쟁사 분석은 필요를 느끼는 팀원만 진행하며, 팀장이 추후 별도로 재조사할 예정이다.

**+ 규칙 적용 완화 (메타 결정).** 위 4건과 시안 비교로 방향성(확정 소구점 3건 · POL-11① ·
톤)이 충분히 공유됐다. 이제 각 화면의 카피·디자인 세부 표현에는 개인 스타일을 허용한다.
**단 POL-11①·POL-01·POL-09처럼 클라이언트가 직접 지목했거나 사실/법적 근거가 걸린 규칙은
그대로 유지된다** — 완화 대상과 유지 대상 구분표는 결정시트 `I-5` 참조.

## 카피 후보 현황 (v3.4 — "확정 현황"에서 명칭 변경)

**어떤 카피도 확정이 아니다.** 두 안이 후보로 나란히 존재한다.

| 안 | 위치 | 성격 |
|---|---|---|
| 기획-1안 | 카피 전략 보고서 §11 | 시안1(정적 카피 중심) 원문 |
| 기획-2안 | 카피 전략 보고서 §"기획-2안 카피", 기능명세 §4.1·4.2·4.4·4.5 | 수행사 내부 작업으로 도출한 문안(구 "확정 카피") |

화면을 만드는 팀원은 두 안 중 하나를 그대로 쓰거나, 섞거나, 자신의 표현으로 새로 써서
결과물을 제출한다. 결정 근거와 대안은 카피 전략 보고서 §6 참조. POL-13 4단 레지스터는
가이드라인으로 완화됐다 — 위 "핵심 변경" 참조.

## 인사이트 페이지 명칭 (v3.1, 참고용 — 확정 아님)

조정할 수 있다. 시안1에는 인사이트/블로그 페이지가 없어 기획-1안 대응 문구는 없다.

```
## 2026-08-__ (_)

### 오늘의 3가지 (WBS ID로)
1. [ ] (ID) 작업명 — 예상 소요
2. [ ] (ID) 작업명 — 예상 소요
3. [ ] (ID) 작업명 — 예상 소요

### 막힌 것
- 증상 →  원인 추정 →  다음 시도

### 오늘 배운 것 / 재사용할 것
- (skill로 만들 후보, CLAUDE.md에 추가할 규칙 등)

### 내일로 넘김
-
```

**규칙 3가지**
1. 하루 최대 3개. 넘으면 다 못 끝내고 죄책감만 남습니다.
2. "막힌 것"은 반드시 3줄로 기록 — 다음 프로젝트에서 같은 삽질 방지
3. "재사용할 것"이 쌓이면 그게 개인 자산

# project-docs

AI 빌더 그룹 랜딩 페이지 프로젝트 문서. **이 폴더의 파일이 항상 최신이다.**

## 문서 목록

| 파일 | 역할 | 변경 권한 |
|---|---|---|
| `기획안_AI빌더그룹_랜딩페이지.md` | 왜 만드는가 · 무엇을 만드는가. 대표님 컨펌 대상 | 대표님 협의 필요 |
| `PRD_AI빌더그룹_랜딩페이지.md` | 기획안을 실행 단위로 옮긴 팀 기준. FR 번호 체계 | 팀 판단으로 갱신 |
| `기획범위확인요청.html` | 대표님께 제출하는 요약본. 위 두 문서에서 추출 | 기획안 변경 시 함께 갱신 |
| `WBS_및_투두관리_AI빌더그룹.md` | 작업 분해 · 일정 | 수시 |
| `devlog.md` | 작업 기록 (배경 / 한 일 / 고민·판단 / 다음) | 세션마다 |

## 작업할 때

- 판단이 필요하면 **PRD**를 먼저 본다. 근거가 필요하면 기획안.
- **`archive/` 는 읽지 않는다.** 옛 버전이라 현재 결정과 어긋난다.
- 구현 기준이 팀 공통 문서(`REQ-` / `FN-` / `POL-` 번호)와 충돌하면 **팀 공통 문서를 따른다.** 이 폴더의 PRD(`FR-` 번호)는 판단 근거용이다.

## 현재 상태

- 기획안 · PRD 모두 **v2-draft**. 대표님 컨펌 시 v2.0으로 확정.
- 대표님 회신 대기 3건: 실전 사례 라이브 링크 노출 동의 / 빌더 프로필 공개 수위 / 본사 표기 수위.
  → 세 건 모두 기본값으로 진행 중이며, 각 문서에 회신 전 진행 방안이 적혀 있다.
